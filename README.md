# about-me

Personal portfolio website for **Md. Shafiul Islam**.

## Features

- Bengali and English language switcher
- Light and dark themes
- Responsive desktop and mobile layout
- Built-in portfolio manager
- Project image upload
- JSON export and import for portable project data

## Manage projects

Open the website and select **পোর্টফোলিও যোগ করুন** / **Manage portfolio**. Add a project name, category, description, URL, and image.

Projects are stored in the current browser using `localStorage`. Use **Export JSON** to download a backup and **Import JSON** to restore or move the list to another browser.

## Run locally

```bash
python3 -m http.server 4173
```
